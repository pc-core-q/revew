# دليل هيكلة المشروع — متجرك الرقمي

موقع عربي (RTL) لعرض خدمات إنشاء المتاجر الإلكترونية، مع لوحة تحكم أمامية تحفظ البيانات في `localStorage`.

## التقنيات
- TanStack Start + React 19 + Vite
- Tailwind CSS v4 (الإعدادات داخل `src/styles.css`)
- أيقونات `lucide-react`

## هيكل الملفات
```text
src/
  routes/
    __root.tsx            الغلاف العام: <html lang="ar" dir="rtl"> + الخطوط (Cairo/Tajawal)
    index.tsx             الصفحة الرئيسية: الهيدر، الواجهة، من نحن، الخدمات، الأعمال، الفوتر
  components/site/
    AdminPanel.tsx        نافذة الدخول (كلمة المرور) + لوحة التحكم (المشاريع والنصوص)
  lib/
    site-store.ts         القيم الافتراضية + منطق القراءة والحفظ في localStorage (useSiteData)
  hooks/
    use-reveal.ts         حركات الظهور عند التمرير (IntersectionObserver)
  assets/hero.jpg         صورة الواجهة
  styles.css              الألوان والتدرجات والظلال والحركات (Design tokens)
```

## كيف تتفاعل المكونات
1. `index.tsx` يستدعي `useSiteData()` فيحصل على `texts` و `projects` ودوال الحفظ.
2. يمرر البيانات والدوال إلى `AdminPanel`.
3. عند الحفظ من اللوحة تُكتب البيانات في `localStorage` ويُطلق حدث `site-data-changed`، فيعيد الخطاف قراءة البيانات وتتحدث الصفحة فورًا.

## منطق localStorage
| المفتاح | المحتوى |
|---|---|
| `site_texts` | كائن نصوص الموقع (العنوان، الوصف، معلومات التواصل...) |
| `site_projects` | مصفوفة المشاريع `{ id, name, description, image, url }` |

- تُقرأ البيانات داخل `useEffect` بعد تحميل الصفحة (لتجنب أخطاء العرض من الخادم).
- إن لم توجد بيانات محفوظة تُستخدم `DEFAULT_TEXTS` و `DEFAULT_PROJECTS`.
- لإعادة الموقع للوضع الافتراضي: احذف المفتاحين من أدوات المطور في المتصفح (Application → Local Storage).
- ملاحظة: البيانات محفوظة في متصفح المستخدم فقط ولا تظهر للزوار الآخرين. للمشاركة الحقيقية يلزم قاعدة بيانات.

## لوحة التحكم
- الدخول: أيقونة القفل الصغيرة في أسفل الفوتر.
- كلمة المرور: `1234` (الثابت `ADMIN_PASSWORD` في `AdminPanel.tsx`). هذه حماية شكلية فقط وليست أمانًا حقيقيًا.
- تبويب "المشاريع": إضافة/حذف مشروع (الاسم، الوصف، رابط الصورة، رابط المتجر).
- تبويب "نصوص الموقع": تعديل جميع النصوص الرئيسية.

## الصيانة والتعديل
- **تغيير الألوان:** عدّل المتغيرات في `:root` داخل `src/styles.css` (`--primary`, `--primary-glow`, ...).
- **إضافة نص قابل للتعديل:** أضف الحقل إلى النوع `SiteTexts` و `DEFAULT_TEXTS` في `site-store.ts`، ثم إلى `TEXT_FIELDS` في `AdminPanel.tsx`، واستخدمه في `index.tsx`.
- **تعديل بطاقات الخدمات:** المصفوفة `SERVICES` في `index.tsx`.
- **حركة الظهور:** أضف الصنف `reveal` لأي عنصر.
- **روابط المشاريع:** كل بطاقة عبارة عن `<a target="_blank" rel="noopener noreferrer">` تفتح المتجر في تبويب جديد.
